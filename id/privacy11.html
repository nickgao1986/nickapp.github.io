倒数日隐私政策

生效日期：2026年8月9日
适用应用：倒数日（Days Matter）（Bundle ID：com.nickgao.accompany）

倒数日坚持隐私优先：事件标题、日期、备注、自定义图标与背景照片等核心内容默认保存在您的设备本地。 我们不强制注册账号，也不向开发者自有服务器上传您的倒数日内容。 仅在您主动使用需要联网的功能（如可选 iCloud 同步、应用内购买）时，相关数据才会按本政策说明进行处理。

一、引言

「倒数日」（以下简称“本应用”）是一款倒数日 / 正数日工具，帮助您记录重要日子、查看距离目标日还有多少天或已经过去多少天，并提供列表与月历展示、本地提醒、桌面小组件、节日库导入、分享海报，以及可选的 iCloud 同步与一次性高级功能解锁。

本隐私政策说明本应用如何处理与您相关的信息。请您在使用前仔细阅读。继续使用本应用，即表示您已了解并同意本政策。如您不同意，请停止使用并卸载本应用。

二、我们如何处理信息

本应用开发者不运营用于收集用户内容的自有后端，不要求您注册应用账号。下列信息主要用于在您设备上实现功能：

  • 事件与内容数据（本地）： 事件标题、备注、目标日期、分类、重复规则、农历开关、计数方式（自动 / 倒数 / 正数）、提醒规则、置顶与收藏状态、自定义图标、背景颜色与背景照片文件等，默认保存在设备本地（应用沙盒、UserDefaults、Documents 等）。
  • 应用设置（本地）： 昵称、外观模式、引导完成状态、云同步开关、会员解锁本地标记、上次同步时间等。
  • 小组件数据（本地 App Group）： 为在桌面展示最近的倒数 / 正数信息，可能通过 App Group（group.com.nickgao.accompany）在主应用与小组件之间共享必要快照，仍保留在您的设备及 Apple 提供的本地共享容器中。

我们不会把上述本地数据用于广告画像、跨应用追踪，也不会出售给第三方。

三、您可能主动触发的联网处理

下列能力仅在您主动使用时才会产生网络传输；不使用则无需为对应功能联网。

  • 可选 iCloud 同步（高级功能）： 若您开启云同步，事件元数据（如标题、日期、规则、设置与昵称等）可能通过 Apple CloudKit 同步到您已登录的 iCloud 账户私人数据库（容器标识：iCloud.com.nickgao.accompany），便于您在自己的设备间同步或换机恢复。 事件背景照片默认仍保存在本机，不会作为照片资源上传到开发者服务器。该云端数据由 Apple 按 iCloud 服务条款与隐私政策处理；开发者不建立独立账号体系保管您的云端档案。
  • 应用内购买： 一次性购买高级功能通过 Apple StoreKit / App Store 完成。支付与账单由 Apple 处理，我们不收集银行卡号等支付敏感信息；应用仅在本地维护解锁状态，并可通过「恢复购买」在您的 Apple ID 下恢复权益。商品标识示例：com.nickgao.accompany.upgrade（以 App Store Connect 实际配置为准）。
  • 系统分享与外链： 您主动分享海报、评分或打开隐私政策等网页时，可能调用系统分享面板，或跳转至 App Store / 浏览器，相关处理遵循对应系统能力或页面服务方的规则。

四、照片与相册

  • 选择照片作为事件背景： 仅在您使用系统照片选择器时，本应用才会读取您明确选中的图片，并压缩后保存在设备本地，用于列表、详情或卡片展示。
  • 系统分享： 您主动生成并分享海报图片时，由系统分享面板完成，接收方由您自行选择。

本应用当前主功能路径不要求访问相机、麦克风，也不采集通讯录或定位信息。

五、设备权限说明

本应用可能申请或使用以下权限 / 系统能力，仅用于对应功能，您可在系统设置中随时管理：

  • 通知：事件到期或提前提醒等本地通知（需您允许通知；提醒时间与规则以您在应用内设置为准）。
  • 照片图库（选择时）：读取您选中的背景照片。

本应用不要求通讯录、精确持续定位、广告追踪等与核心功能无关的权限，也不将您的事件记录用于广告定向。

六、本地存储、删除与安全

  • 本地数据保存在您的设备中。您可在应用内编辑或删除对应事件；卸载应用通常会清除应用沙盒数据。
  • 清除本地数据不会自动取消 Apple ID 下的购买记录；重新安装后通常可通过「恢复购买」找回已购权益。
  • 若您曾开启 iCloud 同步，还需根据需要在 iCloud / 系统设置中管理或删除云端数据。
  • 请妥善保管设备解锁方式。因设备丢失、被他人使用，或您主动分享截图、分享海报而导致的信息泄露风险，由您自行防范。
