家护记隐私政策

生效及更新日期：2026年8月19日
适用应用：家护记（Bundle ID：com.nickgao.homecare）

家护记是一款本地优先的家庭设备保修与维护工具。设备档案、维护记录、附件和设置默认保存在您的设备中； 无需注册应用账号。家护记不在自有服务器上建立家庭设备资料库，不将设备资料用于广告画像、跨应用追踪或出售。

一、我们处理的数据

  • 设备档案：您录入的设备名称、家庭或房产、房间、类别、品牌、型号、序列号、购买信息、保修期限和备注。
  • 维护数据：维护计划、提醒日期、完成记录、费用、服务商名称、服务商电话和备注。
  • 设备附件：您通过系统照片选择器明确选择的设备照片、购买凭证、保修卡或说明书图片，以及您主动从系统文件选择器导入的 PDF 文件。
  • 扫描与查询数据：您主动使用相机扫描或从相册选择照片时，应用会处理其中的文字和条码，用于预填设备资料。使用条码补全商品名称和品牌时，条码可能发送到 Open Products Facts 公共商品数据库查询。
  • 应用设置：通知时间、引导状态、应用锁、iCloud 同步状态和购买权益状态。
  • Widget 快照：为展示近期保修和维护事项，主应用会通过 App Group（group.com.nickgao.homecare）向 Widget 提供必要的设备名称、事项标题、日期和缩略图。

上述数据默认保存在应用沙盒或 Apple 提供的本地共享容器中。相册 OCR 和实时扫描在设备本地完成；条码查询只发送条码本身，不发送设备照片、维护记录或家庭资料。

二、照片与附件

仅当您主动使用系统照片选择器或文件选择器时，应用才会读取您选择的图片或 PDF。文件保存在应用沙盒，用于设备封面或资料附件。 家护记不会浏览未选中的相册内容或文件，也不会将附件上传到开发者服务器。

三、通知

经您授权后，家护记会使用系统本地通知提醒保修到期和维护任务。提醒内容根据您在本机保存的设备与日期生成。 您可以在应用或系统设置中调整提醒时间或关闭通知权限。系统可能因专注模式、低电量、设备关机或权限设置延迟或不展示通知。

四、扫描、条码与说明书搜索

当您主动打开相机扫描功能时，家护记会使用相机识别设备铭牌、保修卡、收据中的文字和条码。相册 OCR 使用您选择的图片在本机处理，识别结果只有在您点击填入或保存后才会写入设备档案。 家护记不会持续拍摄，也不会读取您未选择的照片。

当您主动使用条码商品查询时，应用会向 Open Products Facts 请求公开商品资料。网络服务可能按照其自身隐私政策记录请求日志；家护记不会向该服务发送您的姓名、家庭地址、设备照片或维护记录。查找说明书功能会打开系统浏览器，并由您决定是否访问搜索结果。

五、可选 iCloud 同步

Pro 用户可主动开启 iCloud 同步。开启后，完整备份（包括设备档案、维护数据和图片/PDF 附件）会通过 Apple CloudKit 存储在您 Apple ID 对应的私人数据库中，容器标识为 iCloud.com.nickgao.homecare。

首次同步时，应用会要求您明确选择“上传本机数据”或“从 iCloud 恢复”。后续同步按数据修改时间决定方向。 云端数据由 Apple 按其 iCloud 条款与隐私政策处理；开发者不建立独立账号体系，也不会把备份复制到自有服务器。 关闭同步不会自动删除已有 iCloud 备份。

六、应用内购买

家护记通过 Apple StoreKit 提供非消耗型永久版商品（com.nickgao.homecare.pro.lifetime）。 支付、账单、退款和家庭共享状态由 Apple 处理；应用不接触银行卡号等支付凭证，只读取经过 StoreKit 验证的购买权益。 您可以使用“恢复购买”在同一 Apple ID 下恢复权益。

七、应用锁与安全

当您开启 Face ID 或 Touch ID 应用锁时，生物识别由 Apple 的系统接口完成，应用不会取得或保存您的生物特征。 应用锁相关标记保存在本机；请同时妥善保护设备密码和 Apple ID。

八、导出、恢复、家庭资料包与删除

  • 您可以主动导出 JSON 完整备份、CSV 清单或设备 PDF 报告，导出后的文件由您选择的系统分享目标处理。
  • 您可以通过系统分享导出家庭资料包并交给家人；资料包由您选择的分享目标处理，家护记不会在后台向家人账号同步或建立实时协作空间。
  • 从 JSON 恢复会在您确认后替换当前数据，建议操作前先导出备份。
  • 删除的设备进入回收站并保留 30 天；您也可以选择永久删除。
  • 卸载应用通常会删除本地沙盒数据，但不会自动删除 iCloud 备份或 App Store 购买记录。

九、权限与网络

  • 相机：仅在您主动使用实时设备扫描时识别文字和条码。
  • 照片：读取您通过系统选择器选中的图片。
  • 通知：发送保修与维护任务的本地提醒。
  • Face ID：在您开启应用锁后验证设备持有人。
  • iCloud 与网络：在您使用 iCloud 同步、购买或恢复购买时连接 Apple 服务；在条码查询时连接 Open Products Facts，在说明书搜索时打开您选择的浏览器页面。

家护记的家庭设备功能不请求通讯录、定位或广告追踪权限，也不会在后台访问相机或照片。系统可能根据您使用的其他应用模块显示额外权限提示。

十、您的选择与权利

您可在应用内查看、编辑、导出或删除录入的数据，可在系统设置中撤回照片、通知、Face ID 或 iCloud 权限。 如需管理 CloudKit 数据，可通过 Apple 提供的 iCloud 管理能力操作，或通过下方邮箱联系我们了解处理方式。

十一、未成年人

本应用不专门面向儿童，也不会主动收集年龄信息。未成年人应在监护人指导下使用，且不应在设备备注或附件中保存与功能无关的敏感个人信息。

十二、政策更新

功能或适用规则发生变化时，我们可能更新本政策，并在本页面更新日期。若处理目的、数据类型或第三方服务发生重大变化，会通过合理方式提示。

十三、联系方式

隐私相关问题、建议或投诉请发送邮件至 nickgao1986@gmail.com。

十四、重要提示

家护记是记录与提醒工具，不构成设备安全、维修或保险建议。请以产品说明书、保修条款和专业服务人员意见为准； 对燃气、电气、消防等安全设备进行操作前，应确认具备相应条件和资质。
