简要说明：应用锁在您的设备本地处理数据，不向开发者自有服务器上传您的照片、视频、图案密码、应用选择令牌或保险箱内容。

应用锁（英文名 App Lock，以下简称「本应用」）是一款帮助您管理应用访问、专注用机与保护私密内容的 iOS 工具。主要能力包括：应用锁定、专注模式、使用时长相关展示、图案 / 数字密码解锁、隐私保险箱、智能抠图、智能清理与 PDF 工具等。本政策说明本应用如何处理信息。

本应用依赖苹果系统提供的「屏幕使用时间 / Family Controls」等能力实现应用锁定与专注模式，并非系统自带「屏幕使用时间」应用本身。可用能力以您设备系统版本、授权结果及苹果接口限制为准。请仅在您有权管理的设备上使用相关功能。

2. 我们收集哪些信息

本应用日常运行不向开发者收集个人数据。使用本应用无需注册账号、登录、填写邮箱或手机号。

我们不运营用于接收您以下内容的自有服务器：照片、视频、抠图结果、PDF 文档、图案 / 数字密码、密保答案、隐私保险箱内容、入侵抓拍照片，或您通过 Family Controls 选择的应用令牌。

若您主动通过邮件联系我们，您在邮件中自愿提供的信息仅用于回复支持请求。

3. 功能如何使用数据（均在设备本地）

3.1 应用锁与专注模式

  • 在您授权「屏幕使用时间 / Family Controls」后，本应用可使用系统接口选择需要限制的应用或类别，并通过系统屏蔽页限制访问。
  • 选择结果、锁定状态、临时解锁截止时间、专注模式配置等保存在本机，并可能通过 App Group（group.com.nickgao.lock）在主应用与系统扩展（如 Device Activity Monitor、Shield Configuration、Shield Action、Screen Time Report）之间同步，以便完成重锁、屏蔽页展示与解锁唤起。
  • 上述数据用于实现您开启的锁定与专注功能，不会上传至开发者服务器。

3.2 解锁凭证与生物识别

  • 图案锁、数字密码、密保问题与答案等仅保存在您的设备本地，用于本机校验。
  • 面容 ID / 触控 ID 由系统 LocalAuthentication 完成验证。本应用不会获取、存储或上传您的生物特征原始数据或模板。

3.3 入侵抓拍

若您开启入侵检测，在检测到异常解锁尝试时，本应用可使用相机拍摄照片并保存在设备本地，供您自行查看。该功能需相机权限；照片不会上传至开发者服务器。

3.4 隐私保险箱 / 加密空间

您放入保险箱的照片、视频与文件保存在本应用沙盒内，并使用系统文件保护机制（如锁屏后降低被直接读取的风险）。这不是对绝对安全的承诺，请结合系统锁屏与良好用机习惯使用。内容默认不离开您的设备，除非您主动导出。

3.5 智能抠图、相册与清理、PDF

  • 智能抠图：使用设备端框架（如 Vision、Core Image）处理人像或物体分割，结果仅用于预览、编辑与导出。
  • 智能清理 / 相册相关工具：在您授权相册权限后，于本地分析、压缩或整理媒体；删除或保存由您确认。
  • PDF 工具：导入、合并、拆分、水印、签名、加密等在本地文档库中完成。

临时处理数据在会话结束后丢弃；仅当您选择保存或导出时，结果才会写入相册、文件或其他您指定位置。

3.6 桌面小组件与 URL Scheme

小组件或深度链接（如 piccompress://）可能写入本地标记以打开对应功能。相关状态保存在本机 / App Group，不用于跨应用追踪。

4. 系统权限

本应用仅在功能需要时请求权限，例如：

  • 屏幕使用时间 / Family Controls：用于应用锁定、专注模式及相关限制。

  • 通知（如适用）：用于解锁提醒等您开启的通知能力。

您可随时在 iOS「设置」中关闭权限；关闭后对应功能可能不可用。

App Lock (“the App”) is an iOS utility for managing app access, focus sessions, and private content. Features may include app locking, focus modes, Screen Time–related insights, pattern/numeric unlock, Privacy Vault, smart cutout, smart cleaner, and PDF tools. The App is published as App Lock (Chinese name: 应用锁) with bundle identifier com.nickgao.lock. For privacy questions, see Section 14 (Contact).

We do not collect personal data through routine App use. The App does not require an account, sign-in, email, or phone number.

3. How Features Use Data (On-Device)

3.1 App Lock and Focus Modes

  • After you authorize Screen Time / Family Controls, the App can use system APIs to select apps or categories to restrict and present system Shield screens.
  • Selection state, lock status, temporary-unlock deadlines, and focus settings are stored on-device and may sync via the App Group group.com.nickgao.lock between the main app and system extensions (Device Activity Monitor, Shield Configuration, Shield Action, Screen Time Report) so re-locking, shield UI, and unlock handoff can work.
  • This data is used only to provide features you enable and is not uploaded to developer servers.

3.2 Unlock Credentials and Biometrics

  • Pattern locks, numeric passcodes, and security Q&A are stored locally for on-device verification.
  • Face ID / Touch ID verification is performed by the system (LocalAuthentication). The App does not obtain, store, or upload your biometric raw data or templates.

3.3 Intruder Capture

If enabled, failed unlock attempts may trigger an on-device camera capture stored locally for your review. Camera permission is required. Captures are not uploaded to developer servers.

3.4 Privacy Vault / Encrypted Space

Photos, videos, and files you place in the vault remain in the App sandbox and use system file-protection mechanisms (for example, reduced readability when the device is locked). This is not a guarantee of absolute security—combine it with a device passcode and good habits. Content does not leave your device unless you export it.

3.5 Smart Cutout, Cleaner, and PDF Tools

  • Smart cutout: on-device frameworks (such as Vision and Core Image) create segmentation previews and exports.
  • Smart cleaner / photo tools: with Photos permission, media is analyzed, compressed, or organized locally; deletions/saves require your action.
  • PDF tools: import, merge, split, watermark, sign, and encrypt documents in a local document library.

Temporary processing data is discarded after the session unless you save or export the result.

3.6 Widgets and URL Schemes

Widgets or deep links (such as piccompress://) may write local flags to open a feature. This state stays on-device / in the App Group and is not used for cross-app tracking.

4. Permissions

  • Screen Time / Family Controls: app locking, focus modes, and related restrictions.
  • Camera: intruder capture and in-app capture features where offered.
  • Photos (read/add): choose, process, and save media when you ask.
  • Microphone: only when recording video with audio (if applicable).
  • Face ID / Touch ID: unlock encrypted albums, private files, or related verification.
  • Notifications (if applicable): unlock reminders or other alerts you enable.

You can revoke permissions in iOS Settings. Some features will stop working without them.
