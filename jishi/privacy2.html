简要说明：应用锁在您的设备本地处理数据。我们不向开发者自有服务器上传您的照片、视频、图案数据，或您通过 Family Controls 选择的应用令牌。

本应用不包含广告 SDK、第三方分析 SDK，也不进行跨应用追踪。

应用锁（英文名 App Lock，以下简称「本应用」）是一款帮助您管理应用访问与专注用机的 iOS 工具。当前产品能力主要包括：应用锁定、图案验证、时段锁与临时解锁、专注模式、使用时长相关展示、可选闯入抓拍，以及智能清理、相片清理、智能抠图与 PDF 工具等。本政策说明本应用如何处理信息。

本应用依赖苹果系统提供的「屏幕使用时间 / Family Controls」等能力实现应用锁定与专注模式，并非系统自带「屏幕使用时间」应用本身。可用能力以您设备系统版本、授权结果及苹果接口限制为准。请仅在您有权管理的设备上使用相关功能。

本应用不提供隐私保险箱 / 加密空间、伪装解锁界面、通知栏解锁，也不提供证件 / 护照 / 文凭等官方证件类生成功能。

3. 功能如何使用数据（均在设备本地）

3.1 应用锁与专注模式

  • 在您授权「屏幕使用时间 / Family Controls」后，本应用可使用系统接口选择需要限制的应用或类别，并通过系统屏蔽页限制访问。
  • 选择结果、锁定状态、临时解锁截止时间、专注模式配置等保存在本机，并可能通过 App Group（group.com.nickgao.lock）在主应用与系统扩展（如 Device Activity Monitor、Shield Configuration、Shield Action、Screen Time Report）之间同步，以便完成重锁、屏蔽页展示与解锁流程衔接。
  • 当您在系统屏蔽页点击「解锁」后，扩展仅写入本机 App Group 标记；您需手动打开本应用完成图案验证。本应用不会通过通知中心承载解锁流程。
  • 上述数据用于实现您开启的锁定与专注功能，不会上传至开发者服务器。

3.2 解锁凭证与生物识别

  • 图案锁数据仅保存在您的设备本地，用于本机校验。
  • 面容 ID / 触控 ID 由系统 LocalAuthentication 完成验证。本应用不会获取、存储或上传您的生物特征原始数据或模板。

3.3 闯入抓拍

若您开启闯入检测，在检测到异常解锁尝试时，本应用可使用相机拍摄照片并保存在设备本地，供您自行查看与删除。该功能需相机权限，默认关闭；照片不会上传至开发者服务器。

3.4 智能清理、相片清理、抠图与 PDF

  • 智能清理 / 相片清理：在您授权相册权限后，于本地分析、压缩或整理媒体；删除或保存由您确认。
  • 智能抠图：使用设备端框架（如 Vision、Core Image）处理人像或物体分割，结果仅用于预览、编辑与导出。
  • PDF 工具：导入、合并、拆分、水印、签名、加密等在本地文档库中完成。

临时处理数据在会话结束后丢弃；仅当您选择保存或导出时，结果才会写入相册、文件或其他您指定位置。

3.5 桌面小组件与 URL Scheme

小组件或深度链接（如 piccompress://）可能写入本地标记以打开对应功能（例如智能清理）。相关状态保存在本机 / App Group，不用于跨应用追踪。

4. 系统权限

您可随时在 iOS「设置」中关闭权限；关闭后对应功能可能不可用。

App Lock (“the App”) is an iOS utility for managing app access and focus sessions. Current features mainly include app locking, pattern verification, scheduled and temporary unlock, focus modes, Screen Time–related insights, optional intruder capture, plus smart cleaner, album cleanup, smart cutout, and PDF tools. This Privacy Policy explains how information is handled.

App locking and focus modes rely on Apple’s Screen Time / Family Controls frameworks. The App is not Apple’s built-in Screen Time app. Available capabilities depend on your iOS version, authorization results, and Apple API limits. Use these features only on devices you are authorized to manage.

The App does not offer a Privacy Vault / Encrypted Space, disguised unlock screens, Notification Center–based unlocking, or tools that generate official identity documents such as IDs, passports, or diplomas.

3. How Features Use Data (On-Device)

3.1 App Lock and Focus Modes

  • After you authorize Screen Time / Family Controls, the App can use system APIs to select apps or categories to restrict and present system Shield screens.
  • Selection state, lock status, temporary-unlock deadlines, and focus settings are stored on-device and may sync via the App Group group.com.nickgao.lock between the main app and system extensions (Device Activity Monitor, Shield Configuration, Shield Action, Screen Time Report) so re-locking, shield UI, and unlock handoff can work.
  • When you tap Unlock on a system Shield, the extension only writes a local App Group flag; you then open the App manually to complete pattern verification. The App does not use Notification Center to carry the unlock flow.
  • This data is used only to provide features you enable and is not uploaded to developer servers.

3.2 Unlock Credentials and Biometrics

  • Pattern-lock data is stored locally for on-device verification.
  • Face ID / Touch ID verification is performed by the system (LocalAuthentication). The App does not obtain, store, or upload your biometric raw data or templates.

3.3 Intruder Capture

If enabled, failed unlock attempts may trigger an on-device camera capture stored locally for your review and deletion. Camera permission is required; the feature is off by default. Captures are not uploaded to developer servers.

3.4 Smart Cleaner, Album Tools, Cutout, and PDF

  • Smart cleaner / album tools: with Photos permission, media is analyzed, compressed, or organized locally; deletions and saves require your action.
  • Smart cutout: on-device frameworks (such as Vision and Core Image) create segmentation previews and exports.
  • PDF tools: import, merge, split, watermark, sign, and encrypt documents in a local document library.

Temporary processing data is discarded after the session unless you save or export the result.

3.5 Widgets and URL Schemes

Widgets or deep links (such as piccompress://) may write local flags to open a feature (for example, smart cleaner). This state stays on-device / in the App Group and is not used for cross-app tracking.

4. Permissions

  • Screen Time / Family Controls: app locking, focus modes, and related restrictions.
  • Camera: intruder capture you explicitly enable, and in-app capture where offered by cleaner / cutout flows.
  • Photos (read/add): choose, process, and save media when you ask.
  • Face ID / Touch ID: local identity verification.

You can revoke permissions in iOS Settings. Some features will stop working without them.

5. Local Storage

The App may store preferences, language/theme, feature toggles, local pattern data, app-lock/focus configuration, document files, edit history, and purchase entitlement cache on your device. Deleting the App usually removes sandbox data; items you exported to Photos or Files are not removed automatically.
