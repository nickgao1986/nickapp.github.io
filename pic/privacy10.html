Days Count 隐私政策

生效日期：2026年8月16日
更新日期：2026年8月16日
适用应用：Days Count（Bundle ID：com.nickgao.counten）

Days Count 坚持隐私优先：事件标题、日期、备注、自定义图标与背景照片等核心内容默认保存在您的设备本地。 我们不强制注册账号，也不向开发者自有服务器上传您的倒数日内容。 仅在您主动使用或同意的联网能力时，相关数据才会按本政策说明处理，包括：可选 iCloud 同步、应用内购买、 可选的应用统计分析（友盟+）、可选的 AI 文案润色（通义千问）。

一、引言

「Days Count」（以下简称“本应用”，产品名亦可能显示为「倒数日」）是一款倒数日 / 正数日工具，帮助您记录重要日子、查看距离目标日还有多少天或已经过去多少天，并提供列表与月历展示、本地提醒、桌面与锁屏小组件、节日库导入、分享海报，以及可选的语音输入、AI 文案润色、应用统计分析、iCloud 同步与一次性高级功能解锁。

本隐私政策说明本应用如何处理与您相关的信息。请您在使用前仔细阅读。继续使用本应用，即表示您已了解并同意本政策。如您不同意，请停止使用并卸载本应用。 使用条款请参阅 用户协议。

二、我们如何处理信息

本应用开发者不运营用于收集用户内容的自有后端，不要求您注册应用账号。下列信息主要用于在您设备上实现功能：

  • 事件与内容数据（本地）： 事件标题、备注、目标日期、分类、重复规则、农历开关、计数方式（自动 / 倒数 / 正数）、提醒规则、置顶与收藏状态、自定义图标、背景颜色与背景照片文件等，默认保存在设备本地（应用沙盒、UserDefaults、Documents 等）。
  • 应用设置（本地）： 昵称、外观模式、引导完成状态、云同步开关、会员解锁本地标记、上次同步时间等。
  • 小组件数据（本地 App Group）： 为在桌面展示最近的倒数 / 正数信息，可能通过 App Group（group.com.nickgao.counten）在主应用与小组件之间共享必要快照，仍保留在您的设备及 Apple 提供的本地共享容器中。

我们不会把上述本地数据用于广告画像、跨应用追踪，也不会出售给第三方。

三、您可能主动触发的联网处理

下列能力仅在您主动使用时才会产生网络传输；不使用则无需为对应功能联网。

  • 可选 iCloud 同步（免费可选）： 若您开启云同步，事件元数据（如标题、日期、规则、设置与昵称等）可能通过 Apple CloudKit 同步到您已登录的 iCloud 账户私人数据库（容器标识：iCloud.com.nickgao.counten），便于您在自己的设备间同步或换机恢复。 事件背景照片默认仍保存在本机，不会作为照片资源上传到开发者服务器。该云端数据由 Apple 按 iCloud 服务条款与隐私政策处理；开发者不建立独立账号体系保管您的云端档案。
  • 应用内购买： 一次性购买高级功能通过 Apple StoreKit / App Store 完成。支付与账单由 Apple 处理，我们不收集银行卡号等支付敏感信息；应用仅在本地维护解锁状态，并可通过「恢复购买」在您的 Apple ID 下恢复权益。商品标识：com.nickgao.counten.upgrade。
  • 系统分享与外链： 您主动分享海报、评分或打开隐私政策等网页时，可能调用系统分享面板，或跳转至 App Store / 浏览器，相关处理遵循对应系统能力或页面服务方的规则。
  • 可选 AI 文案润色（通义千问 / 阿里云百炼）： 仅当您在应用内主动点击「AI 润色」等按钮，并确认同意将内容发送至云端后，本应用才会把您当前编辑中的事件标题与备注文本发送至阿里云计算有限公司运营的通义千问 / 百炼服务，用于生成更通顺的标题或备注建议。 我们不会因此上传您的录音、照片、相册原图、通讯录或定位信息；亦不会将事件列表做批量后台上传。 该处理由第三方云服务完成，适用其服务条款与隐私政策；返回的建议文案是否采用由您自行决定，您也可随时不使用该功能。
  • 可选应用统计分析（友盟+ U-App）： 仅在您于应用内明确允许统计分析后，本应用才会初始化友盟+ SDK，用于了解功能使用情况、改进产品体验（例如页面访问、按钮点击、购买流程结果、语音/AI 功能使用次数等产品交互数据，以及用于统计的设备标识等信息）。 统计分析不会上传您的事件标题全文、备注内容、照片或录音。 若您选择「暂不允许」，本应用将不初始化友盟，也不进行上述统计上报；您仍可正常使用本地记录、提醒、小组件等核心功能。 友盟相关处理适用其隐私政策与服务条款。

四、您可能主动授权的本地能力

  • 通讯录（可选导入）： 仅在您使用生日导入功能并授权后，本应用才会读取您选中或系统返回的联系人姓名与生日字段，用于创建倒数日事件。我们不会将通讯录上传至开发者服务器。
  • 日历（可选导入）： 仅在您使用日历导入功能并授权后，本应用才会读取相关日历事件供您选择导入。我们不会批量上传您的日历内容。
  • 语音输入： 语音经系统麦克风采集后，由 Apple 提供的语音识别能力转为文字，用于填写事件标题或备注。 本应用不会把录音文件上传到开发者服务器或千问服务。 若系统在个别机型或设置下需要联网完成识别，相关处理遵循 Apple 语音识别规则；您可在系统设置中关闭麦克风或语音识别权限。
  • 照片： 仅在您使用系统照片选择器时，本应用才会读取您明确选中的图片，并压缩后保存在设备本地，用于事件背景或卡片展示。本应用不扫描您的全部相册。
  • 通知： 用于按您设定的规则发送本地提醒。提醒内容保存在本机，不经过开发者服务器。
  • Face ID / Touch ID： 用于解锁应用或查看隐藏事件。生物识别数据由 iOS 处理，本应用无法读取或存储生物模板。

本应用可能申请或使用以下权限 / 系统能力，仅用于对应功能，您可在系统设置中随时管理：

六、本地存储、删除与安全

  • 本地数据保存在您的设备中。您可在应用内编辑或删除对应事件；卸载应用通常会清除应用沙盒数据。
  • 清除本地数据不会自动取消 Apple ID 下的购买记录；重新安装后通常可通过「恢复购买」找回已购权益。
  • 若您曾开启 iCloud 同步，还需根据需要在 iCloud / 系统设置中管理或删除云端数据。
  • 请妥善保管设备解锁方式。因设备丢失、被他人使用，或您主动分享截图、分享海报而导致的信息泄露风险，由您自行防范。
